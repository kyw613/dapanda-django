> **흥정에 지친 사용자들을 위해, 중고 물품을 간편하게 경매로 거래할 수 있도록 설계된 온라인 경매 플랫폼.**
>
> 사용자는 다양한 경매 물품을 쉽게 판매하거나 구매할 수 있습니다.


## 제안배경 및 필요성

---

**중고 거래 시장의 문제점 해결**

기존의 중고 거래는 가격 협상, 시간 조율 등의 번거로움이 존재하여 사용자 경험이 저하되는 경우가 많습니다. 이를 해결하기 위해 **흥정 없이 즉시 거래 가능한 경매 시스템**을 도입하여 거래 편의성을 높이고자 합니다.
